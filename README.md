## 🎨 Integrated 3D Coverflow Carousel Component

This repository features the enterprise-grade **Coverflow 3D Carousel** built for high-performance visual navigation:

- **Direct DOM Manipulation (`requestAnimationFrame`):** Zero React re-render bottleneck for butter-smooth 60–120 FPS glide.
- **Physical Drag Inertia:** Dynamic momentum velocity throw capped to 2 cards flick with exponential ease-out settle.
- **Toroidal Ring Offsets:** Infinite looping without duplicating DOM nodes via modulo arithmetic.
- **Accessible & Keyboard Ready:** Full support for `ArrowLeft` / `ArrowRight`, touch screens, and assistive tags.
